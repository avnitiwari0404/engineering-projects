# Intelligent Distance-Controlled Barrier

## Project Status
In Progress

## Objective

To design and build a barrier that automatically responds to the distance of an approaching object.

## Components

- Arduino
- Ultrasonic sensor
- Servo motor
- Breadboard
- Jumper wires
- Power supply

## How It Works

The ultrasonic sensor measures the distance between the sensor and an approaching object.

The Arduino processes this distance and controls the servo motor accordingly.

When the object reaches the defined distance threshold, the barrier responds automatically.
